# 已退役的自动资料匹配链路

归档日期：2026-08-24

这些文件曾用于从第三方网站查询书籍、电影、专辑和游戏资料，并通过 Obsidian 专用接口返回封面。现在记录改为完全由 Obsidian 本地模板手动维护，因此它们不再位于运行代码中，也不应重新启用。

- `backend/media_metadata_service.py`：旧的资料提供商客户端和封面下载器。
- `backend/media_matching.py`：旧的标题候选排序器。
- `tests/`：对应的旧自动匹配测试。

服务器上的资料查询接口、封面代理和专用凭据已移除。网站现有的手工媒体展示/编辑接口仍保留，以免影响无关的网站功能。原始实现也保留在 Git 历史中，便于必要时回滚；归档文件不包含任何密钥。
