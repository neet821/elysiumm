# Elysium 整站内部重构与成熟组件整合实施记录

## 全局约束

以用户本任务批准的完整计划为规范。保留外层目录、页面效果、网站账号、现有数据、表结构和迁移历史；仅新增个人歌单必要迁移。继续当前重构分支，保留原有修改，不合并 runtime-first-rebuild。本地验证、分批中文提交，不推送、合并或部署生产。不修改 FlClash、系统代理、系统证书。第三方依赖固定版本且内部服务仅限回环或受限网络。

## Task 1: 基线、入口与生命周期

记录路由顺序、权限、响应与实时消费者。审查未挂载的路由草稿；统一认证依赖，main 仅保留组装、中间件、生命周期。清理、音乐、直播任务各一次并取消等待。先补行为测试，记录已有失败。保留公开兼容地址直到消费者证据充分。

## Task 2: 前端按职责拆分

保持现役页面、导航、样式加载顺序和选择器不变。先为当前行为补测试，再拆分 ContentHomePage、MusicRoomPlayer、useVideoRoom 的展示、通信与状态职责。不得增加第二个 Socket 连接或独立权威播放状态。功能代码沿用 features，禁止机械按行数拆分。先完成内容首页的组装与展示拆分，再音乐播放器，最后视频 Hook。现有未跟踪 internalRefactor 测试需审查，不能当成已完成工作。

## Task 3: 后端领域与实时边界

模型与 schemas 按领域组织且保留统一入口和同一 metadata，纯拆分不加迁移。分离实时实例、连接状态、事件与业务，HTTP 复用权限业务，保留单 worker 和现役本地视频。拆分独立文件处理职责。验证 metadata、路由权限、重连、Range、私信。

## Task 4: 旧功能审计与退役

审查独立书签、旧书籍目录、资源求助、旧音乐桥接的前端、脚本、回滚、同步消费者。逐项记录替代入口、测试退役说明及外部兼容风险；不删除数据库数据、迁移、历史路径兼容、现役影音书游记录或证据不足的公开入口。

## Task 5: 内部音乐服务与个人歌单

固定版本 NeteaseCloudMusicApiEnhanced 与 UNM 的内部服务，UNM 仅匹配解析，关闭重复解析；保留 QQ/Audius，管理员凭据不出服务端。明确播放/试听/不可用/临时错误和匹配证据。新增私有个人歌单及有序歌曲关系；网易云公开 ID/规范链接预览后幂等导入独立副本，部分缺失明确呈现，追加房间队列不覆盖。补越权、超时、重试、迁移空库/旧库测试。

## Task 6: 同步协议增强

兼容扩展实例 ID、操作序号、媒体身份，拒绝重复乱序旧曲目控制。队列操作增删移动防止旧快照覆盖；RTT 估时、重连先权威快照；共用音乐视频时钟基础而保留各自纠偏。不复制许可证未知的 NeriPlayer 源码。

## Task 7: tus 网页上传

固定版本 Uppy core/tus 与 tusd，仅管理员文件和访客传输，按需加载保留 UI。网站管理身份用途配额校验入库，私有临时文件，创建续传完成鉴权、并发配额、凭据过期取消清理、幂等完成。保留旧下载分享令牌轮换 Range；真实断线/重启恢复验证后才能删旧网页上传；public_sync 协议不改。

## Task 8: 全量验证与交付

按批审查真实 diff、测试并中文提交。记录架构、第三方版本许可、退役证据与兼容项。最终发布门禁、回滚演练、桌面手机验收，再单独本地预览供用户手动体验。不得以模拟上游通过替代真实音乐集成验证。监控备份替换、CMS 等额外服务不在范围。
