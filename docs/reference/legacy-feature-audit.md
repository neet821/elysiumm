# 旧功能与兼容入口审计

本清单记录整站重构期间对旧功能删除的消费者核验。代码内无调用不等于
外部客户端无人使用；无法取得生产访问日志或外部客户端清单时，公开 API、
数据库表和历史路径按兼容接口保留。

## 独立书签管理

- **本地消费者**：独立书签管理页面已从当前路由删除，但 `/api/homepage` 仍经
  `backend/homepage_service.py` 读取公开书签并生成首页收藏卡片；书签路由仍提供
  导入、导出、备份和恢复，配置与浏览器验收仍覆盖备份流程。
- **替代入口**：首页公开收藏卡片继续展示公开书签；数据维护仍走现有书签 API。
- **决定**：保留书签模型、路由、服务、数据、备份文件和相关检查。不能把独立页面
  退役误判为书签数据链路可删除。
- **外部风险**：没有当前生产请求日志和外部客户端清单，不能证明公开接口无人使用。

## 旧书籍目录 API

- **本地消费者**：独立 Books 页面已移除，但 `Book`、`BookList` 和关联记录仍供
  `backend/book_service.py`、`backend/media_service.py`、`backend/routers/media.py`、
  `backend/admin_dashboard_service.py` 及首页/后台统计使用；Phase 10 浏览器验收
  仍显式请求 `/api/books`。
- **替代入口**：影音书游记录中的阅读状态和管理接口仍是现役入口；不等同于旧独立书库页面。
- **决定**：保留 API、模型、数据和全部迁移；不删除历史记录或改表。
- **外部风险**：旧书籍目录 API 曾有一份 48 小时零请求记录，但活跃内部消费者仍在，
  因此该记录不足以支持删除。

## 资源求助

- **本地消费者**：当前前端没有找到调用方；FastAPI 仍挂载 `/api/resource-requests`
  的公开查询及登录用户创建、回复等接口，模型与 schema 仍在入口导入链中。
- **替代入口**：尚无已确认的等价功能入口。
- **决定**：保留路由、模型、数据、迁移和历史维护脚本。没有外部调用证据不能证明
  已无 API 客户端。
- **外部风险**：公开路由的生产访问情况未知；删除会改变外部可观察行为。

## 旧 Mineradio provider HTTP 桥

- **本地消费者**：活动音乐路由由 `backend/music` 的直接适配器注册并使用；浏览器播放
  使用 `/api/music/stream/{provider}/{track_id}`。FastAPI 路由中没有旧
  `/mineradio-api` 端点。旧 `backend/music_providers` 仅由该兼容包自己的测试和
  `MUSIC_PROVIDER_LEGACY_COMPAT` 配置分支引用；部署及 smoke 脚本没有需要保留的调用。
- **替代入口**：保留网易云、QQ、Audius 的直接服务端适配器和网站音乐播放路由。
  当前 `MineradioPage` 是 Elysium 听歌房，不是已退役的独立 Mineradio 服务，必须保留。
- **决定**：删除仅作为回滚模式存在的旧 `backend/music_providers` 包及专属桥接测试；
  移除旧配置项，发布配置检查拒绝再次配置这些已退役变量。直接适配器的重试、错误
  隔离、响应大小限制与 Audius 播放契约由现役测试覆盖。
- **测试处理**：移除依赖旧 Mineradio 合同的专属测试；保留现役直接 provider 行为测试，
  并增加静态退役合同检查，确保配置/路由不会重新暴露旧桥。
- **外部风险**：无法排除未记录的旧客户端尝试访问历史 `/mineradio-api` 地址；该地址在
  当前 FastAPI 中本来就没有实现。本次不新增兼容重定向，也不影响数据库或音乐房间页面。

## 明确保留

- 书签、旧 Books API 与资源求助 API 的数据和迁移。
- 生产数据、全部历史 Alembic 迁移及历史影音文件路径兼容。
- `frontend/src/pages/MineradioPage.jsx` 和当前 Elysium 音乐房行为。
- 不确定外部消费者是否存在的公开 API 与重定向；未来若要退役，需补充访问日志窗口和
  消费者清单，再单独提交行为变更。
