# Historical Mineradio attribution directory

Elysium no longer runs the standalone Mineradio Node/Electron application.
The production website uses the native React music-room feature and direct
FastAPI providers. This directory retains upstream attribution and licensing
files for migration history; its former server, package manifest and runtime
assets are not a deployable service.

See `LICENSE`, `NOTICE.md`, `UPSTREAM.md` and
`BLUE_ALBUM_INTEGRATION.md` for the retained attribution boundary.
